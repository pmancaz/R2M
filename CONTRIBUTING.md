# Contributing

I built Read To Me for my own reading and am sharing it as part of learning to build software with AI assistance. Useful bug reports, small fixes and ideas are welcome. I can't promise a release or support schedule.

For a bug, include your macOS version, Apple Silicon model, the steps you took, and what you expected to happen. A short, public example is helpful. Leave private papers, account details, full chat histories and downloaded model files out of issues and pull requests.

For a change, explain the problem it solves and how you checked it. Keep the author's original wording available, preserve reversible cleanup, keep inference local, and retain upstream model/package credits and licences. For a larger change, opening an issue first will make it easier to work out whether it fits the project.

Build and test commands are in [docs/BUILDING.md](docs/BUILDING.md). Contributions to the application source use the same AGPL-3.0-only licence as the project.
