# Voice previews

These short synthetic samples were generated locally with the pinned Kokoro-82M model and the five voice packs listed in `../models.json`.

All five read this project-specific sentence:

> This is Read To Me. I turn articles and papers into narration you can take with you.

Format: mono 24 kHz, 16-bit PCM WAV. These are generated speech samples, not model weights or recordings of a user. Model and voice credits: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0).
